# 🎵 Audio Separator

Веб-приложение для разделения аудио на вокал и инструментал прямо в браузере. Полностью клиентское — файлы никуда не загружаются.

## ✨ Возможности

- 🔒 **100% приватность** — вся обработка происходит локально в браузере
- ⚡ **Мгновенная обработка** — не требует загрузки ML-моделей
- 🎯 **Классические методы** — использует Center Channel Extraction
- 💾 **Экспорт** — скачивание результатов в WAV формате
- 🌐 **Работает везде** — не требует доступа к внешним ресурсам

## 🎯 Как это работает

Приложение использует метод **Center Channel Extraction** (извлечение центрального канала):

- Вокал обычно панорамирован в центр стерео-панорамы
- Инструменты часто панорамированы влево или вправо
- Алгоритм математически разделяет эти компоненты:
  - **Вокал** = (L + R) / 2 (центральный канал)
  - **Инструментал** = оригинал - вокал

### Преимущества этого подхода:
- ✅ Не требует загрузки ML-моделей (100+ MB)
- ✅ Работает мгновенно
- ✅ Не зависит от внешних серверов
- ✅ Работает в любом браузере с Web Audio API
- ✅ Полностью приватно

### Ограничения:
- ⚠️ Требует стерео-аудио (не работает с моно)
- ⚠️ Качество зависит от сведения трека
- ⚠️ Лучше всего работает с треками, где вокал чётко в центре

## 🌍 Деплой на GitHub Pages

### Через GitHub Actions (рекомендуется)

Создай `.github/workflows/deploy.yml`:

```yaml
name: Deploy to GitHub Pages
on:
  push:
    branches: [main]
permissions:
  contents: read
  pages: write
  id-token: write
jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
      - run: npm ci
      - run: npm run build
      - uses: actions/upload-pages-artifact@v3
        with:
          path: dist
      - uses: actions/deploy-pages@v4
```

Затем: **Settings → Pages → Source → GitHub Actions**

## 📊 Технические детали

- **Метод:** Center Channel Extraction
- **Формат входа:** Стерео аудио (MP3, WAV, OGG, FLAC, M4A, AAC, WebM)
- **Формат выхода:** WAV (стерео)
- **Обработка:** Web Audio API
- **Размер:** ~200 KB (без ML-моделей)

## 🎵 Лучшие результаты

Метод Center Channel Extraction лучше всего работает с:
- ✅ Поп-музыкой (вокал обычно в центре)
- ✅ Рок-музыкой
- ✅ Караоке-треками
- ✅ Треками с чётким стерео-разделением

Хуже работает с:
- ⚠️ Моно-записями
- ⚠️ Треками с панорамированным вокалом
- ⚠️ Электронной музыкой с обработанным вокалом
