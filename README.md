# 🎵 Audio Separator

Веб-приложение для разделения аудио на 6 дорожек прямо в браузере. Полностью клиентское — файлы никуда не загружаются.

## ✨ Возможности

- 🔒 **100% приватность** — вся обработка происходит локально в браузере
- 🧠 **HT-Demucs FT** — state-of-the-art модель разделения (SDR 9.19 dB для вокала)
- 🎼 **Вокал → MIDI** — транскрипция вокала в MIDI с помощью Spotify Basic Pitch
- 🎤 **Вокальный фильтр** — специализированная фильтрация для выделения исключительно вокальных нот
- ✏️ **MIDI Редактор** — визуальный и текстовый редактор с воспроизведением
- 🧹 **MIDI Cleaner** — автоматическая очистка от ложных и мелких нот
- 🎵 **Автогенерация текста** — создание lyrics.json на основе MIDI
- 📝 **Привязка текста** — автоматическая привязка нот к lyrics.json
- 🎵 **2 дорожки** — Vocals и Instrumental
- 🌐 **WebGPU + WASM** — использует WebGPU при наличии, fallback на WASM
- 💾 **Кэширование** — модели кэшируются в CacheStorage после первой загрузки
- ⬇️ **Экспорт** — скачивание результатов в WAV, MIDI и Karaoke JSON форматах

## 🎼 Транскрипция вокала в MIDI

После разделения аудио можно конвертировать вокальную дорожку в MIDI файл:

### Модель
Используется **Spotify Basic Pitch** — лёгкая модель для транскрипции аудио в MIDI:

| Параметр | Значение |
|----------|----------|
| Размер | ~230 KB |
| Вход | Аудио 22050 Hz, моно, окно 2 секунды |
| Выход | MIDI ноты с velocity |
| Лицензия | Apache-2.0 |

### Как это работает
1. **Подготовка аудио** — вокал ресемплится в 22050 Hz и конвертируется в моно
2. **Нарезка на окна** — аудио разбивается на перекрывающиеся окна по 2 секунды
3. **Инференс** — каждое окно обрабатывается моделью Basic Pitch
4. **Постобработка** — тензоры конвертируются в MIDI ноты (start, end, pitch, velocity)
5. **Генерация MIDI** — создаётся Standard MIDI File (format 0)

### Использование
1. Разделите аудио на вокал и инструментал
2. Нажмите кнопку "🎼 Создать MIDI" рядом с вокальной дорожкой
3. Дождитесь завершения транскрипции (10-30 секунд для 3-минутного трека)
4. Нажмите "✏️ Редактировать" для открытия MIDI-редактора (опционально)
5. Скачайте MIDI файл кнопкой "⬇️ MIDI" или Karaoke JSON кнопкой "⬇️ Karaoke JSON"

### Ограничения
- Транскрипция не идеальна для сложного вокала с сильным вибрато или эффектами
- MIDI может потребовать ручной чистки в DAW
- Модель покрывает диапазон MIDI 21-108 (пиано)

## ✏️ MIDI Редактор

После транскрипции доступен продвинутый редактор для исправления ошибок и тонкой настройки:

### Возможности
- 🎹 **Piano Roll визуализатор** — интерактивное отображение нот на пианино-ролле
- 🔊 **Воспроизведение** — прослушивание MIDI прямо в браузере с регулировкой громкости
- ✏️ **Редактирование нот** — изменение pitch, start, end через UI
- 🖱️ **Перетаскивание нот** — drag & drop для перемещения нот по времени и высоте
- ➕ **Добавление нот** — двойной клик по пустому месту для создания новой ноты
- 📝 **JSON редактор** — прямое редактирование структуры с подсветкой синтаксиса
- 🗑️ **Удаление нот** — удаление ложных срабатываний
- 📊 **Статистика** — количество нот, фраз, BPM, диапазон

### Использование
1. После транскрипции нажмите кнопку "✏️ Редактировать"
2. Откроется модальное окно с двумя вкладками:
   - **Визуальный редактор** — piano roll с возможностью кликать по нотам
   - **JSON редактор** — текстовое редактирование с валидацией
3. В визуальном редакторе:
   - **Клик по ноте** — выбор для редактирования
   - **Перетаскивание ноты** — зажмите ЛКМ на ноте и перемещайте (горизонтально — время, вертикально — высота)
   - **Двойной клик по пустому месту** — создание новой ноты в этой позиции
   - Изменение параметров в панели справа
   - Воспроизведение для проверки
4. В JSON редакторе:
   - Прямое редактирование структуры
   - Автоматическая валидация
   - Мгновенное применение изменений
5. Нажмите "💾 Сохранить JSON" для скачивания исправленной версии

### Формат Karaoke JSON
```json
{
  "phrases": [
    {
      "notes": [

        { "start": 1.115, "end": 1.207, "note": 74 }

    }
  ],
```

## 🧹 MIDI Cleaner

Автоматическая очистка MIDI от ложных и мелких нот:

### Возможности
- 🗑️ **Удаление коротких нот** — фильтрация нот короче заданного порога (по умолчанию 80ms)
- 🗑️ **Удаление длинных нот** — фильтрация нот длиннее заданного порога (по умолчанию 5s)
- 🔗 **Слияние легато** — объединение соседних нот одной высоты
- 📏 **Удаление перекрытий** — очистка перекрывающихся нот
- ⚙️ **Настраиваемые параметры** — все пороги можно настроить через UI

### Использование
1. Откройте MIDI-редактор
2. Настройте параметры очистки в панели "🧹 MIDI Cleaner"
3. Нажмите "🧹 Очистить MIDI"
4. Проверьте результат в piano roll
5. При необходимости повторите с другими параметрами

### Параметры очистки
- **Мин. длительность ноты** — удаляет ноты короче этого значения (сек)
- **Макс. длительность ноты** — удаляет ноты длиннее этого значения (сек)
- **Порог легато** — сливает соседние ноты одной высоты, если промежуток меньше порога (сек)
- **Мин. промежуток** — удаляет перекрывающиеся ноты (сек)

## 🎤 Вокальный фильтр

Специализированная фильтрация для выделения исключительно вокальных нот:

### Возможности
- 🎵 **Фильтр по диапазону нот** — удаление нот вне типичного вокального диапазона (MIDI 40-80, E2-G5)
- 🎚️ **Спектральная фильтрация** — выделение частот характерных для вокала (80-1000 Hz)
- 📊 **Фильтр по длительности** — удаление очень коротких нот (артефактов)
- ⚙️ **Настраиваемые параметры** — все пороги можно настроить через UI

### Использование
1. Откройте MIDI-редактор
2. Разверните панель "🎤 Вокальный фильтр"
3. Включите нужные фильтры:
   - **Спектральная фильтрация** — удаляет частоты вне вокального диапазона
   - **Фильтр по диапазону нот** — удаляет ноты вне диапазона E2-G5
   - **Фильтр по длительности** — удаляет ноты короче 50ms
4. Настройте параметры под ваш трек
5. Фильтр применяется автоматически при изменении настроек

### Параметры фильтра
- **Мин./Макс. частота** — диапазон вокальных частот (по умолчанию 80-1000 Hz)
- **Мин./Макс. нота** — диапазон вокальных нот (по умолчанию MIDI 40-80)
- **Мин. длительность** — минимальная длительность ноты (50ms)

### Рекомендации
- Для мужского вокала: MIDI 40-70 (E2-A4)
- Для женского вокала: MIDI 50-80 (D3-G5)
- Для универсального использования: MIDI 40-80 (E2-G5)

## 📝 Привязка текста (Lyrics Aligner)

Автоматическая привязка нот к тексту песни:

### Возможности
- 🎤 **Автоматическая генерация** — создание lyrics.json на основе MIDI
- 📄 **Импорт lyrics.json** — загрузка готового текста с таймингами
- 🔗 **Автоматическая привязка** — распределение нот по символам текста
- ⬇️ **Экспорт выровненного файла** — готовый формат для караоке-системы

### Автоматическая генерация текста

Самый простой способ получить lyrics.json — сгенерировать его автоматически из MIDI:

1. Откройте MIDI-редактор
2. В панели "🎤 Автоматическая генерация текста":
   - Выберите текст-заглушку (например, "la", "♪", "да")
   - Выберите режим:
     - **Режим фраз** — каждая фраза = один сегмент
     - **Режим слогов** — каждая нота = отдельный слог
   - Нажмите "🎤 Сгенерировать текст"
3. Отредактируйте текст в JSON редакторе (замените заглушки на реальный текст)
4. Скачайте готовый lyrics.json или выровненный файл

### Ручной импорт lyrics.json

Если у вас уже есть текст с таймингами:

1. Подготовьте файл lyrics.json
2. Откройте MIDI-редактор
3. В панели "📝 Импорт текста" загрузите файл
4. Ноты автоматически привяжутся к тексту
5. Нажмите "⬇️ Скачать выровненный файл"

### Формат lyrics.json
```json
{
```

## 📊 Технические детали

- **Модель:** Demucs HT (через demucs-web)
- **Вход:** Стерео аудио (MP3, WAV, OGG, FLAC, M4A, AAC, WebM)
- **Выход:** 2 WAV файла (vocals, instrumental)
- **Формат входа:** waveform [1, 2, 343980] + magSpec [1, 4, 2048, 336]
- **Формат выхода:** 4 дорожки (drums, bass, other, vocals)
- **Чанк:** 343980 samples (7.8s @ 44.1kHz)
- **Overlap:** 25% overlap-add для плавности

## 🔄 Как это работает

### Разделение аудио
1. **Загрузка аудио** — файл декодируется через Web Audio API
2. **Загрузка модели** — demucs-web загружает оптимизированную модель (170MB) и кэширует её
3. **Разбиение на чанки** — аудио разбивается на 7.8-секундные сегменты с 25% перекрытием
4. **Подготовка входа** — для каждого чанка создаётся waveform и magnitude spectrogram
5. **Инференс** — модель обрабатывает оба входа и возвращает 4 дорожки
6. **Извлечение stems** — Vocals = vocals stem, Instrumental = drums + bass + other
7. **Overlap-add** — чанки собираются обратно с учётом перекрытий
8. **Нормализация** — сигнал нормализуется до 0.95 peak
9. **Экспорт** — результаты кодируются в WAV для воспроизведения/скачивания

### Транскрипция в MIDI
1. **Подготовка вокала** — ресемплинг в 22050 Hz, конвертация в моно
2. **Нарезка на окна** — разбивка на 2-секундные окна с перекрытием
3. **Инференс Basic Pitch** — обработка каждого окна моделью
4. **Постобработка** — извлечение нот из тензоров (note, onset, contour)
5. **Генерация MIDI** — создание Standard MIDI File (format 0)
6. **Генерация Karaoke JSON** — группировка нот по фразам, оценка BPM

### MIDI Редактор
1. **Визуализация** — рендеринг piano roll на Canvas API
2. **Воспроизведение** — синтез через Tone.js с планированием нот
3. **Редактирование** — изменение параметров нот через UI или JSON
4. **Валидация** — проверка синтаксиса JSON в реальном времени
5. **Экспорт** — сохранение исправленной версии

### MIDI Cleaner
1. **Фильтрация коротких нот** — удаление артефактов короче порога
2. **Фильтрация длинных нот** — удаление аномально длинных нот
3. **Слияние легато** — объединение соседних нот одной высоты
4. **Удаление перекрытий** — очистка перекрывающихся нот
5. **Группировка в фразы** — восстановление структуры фраз

### Вокальный фильтр
1. **Фильтр по диапазону нот** — удаление нот вне вокального диапазона (E2-G5)
2. **Спектральная фильтрация** — выделение частот 80-1000 Hz (вокальный диапазон)
3. **Фильтр по длительности** — удаление очень коротких нот (<50ms)
4. **Автоматическое применение** — фильтр применяется при изменении настроек

### Привязка текста
1. **Автогенерация** — создание lyrics.json на основе MIDI (текст-заглушки)
2. **Импорт lyrics.json** — загрузка готового текста с таймингами
3. **Поиск нот в сегментах** — для каждого сегмента текста находятся ноты
4. **Распределение по символам** — ноты равномерно распределяются по символам текста
5. **Генерация выровненного файла** — создание итогового JSON с привязкой

### Разделение аудио
- Первая загрузка модели занимает время (170 MB)
- Разделение на слабых машинах может занять несколько минут
- GitHub Pages лимит трафика: 100 GB/месяц
- WebGPU может не работать на старых GPU или в некоторых браузерах
- **VPN может не понадобиться** — приложение автоматически пробует несколько зеркал (hf-mirror.com, hub.nuaa.cf)
- Если все зеркала недоступны — нужен VPN для первой загрузки
- После первой загрузки модель кэшируется в браузере
- Модель оптимизирована для браузера, но всё ещё требует значительных ресурсов

### Транскрипция
- Транскрипция не идеальна для сложного вокала с сильным вибрато или эффектами
- Могут быть ложные срабатывания или пропущенные ноты
- Используйте MIDI-редактор для исправления ошибок перед скачиванием

### MIDI Редактор
- Воспроизведение может иметь небольшую задержку на слабых устройствах
- Piano Roll оптимизирован для треков до ~5 минут (для более длинных может потребоваться прокрутка)
- JSON редактор требует валидного синтаксиса для применения изменений

### MIDI Cleaner
- Автоматическая очистка может удалить легитимные короткие ноты (например, стаккато)
- Пороги очистки требуют ручной настройки под конкретный трек
- Слияние легато может объединить ноты, которые должны быть раздельными

### Вокальный фильтр
- Фильтр по диапазону нот может удалить легитимные высокие/низкие ноты
- Спектральная фильтрация может ослабить вокал с нестандартным тембром
- Рекомендуется сначала очистить MIDI, затем применять вокальный фильтр
- Настройки фильтра зависят от типа вокала (мужской/женский/детский)

### Привязка текста
- Автоматическая генерация создаёт текст-заглушки (требуется ручная редакция)
- Требует точных таймингов в lyrics.json для ручной привязки
- Распределение нот по символам может быть неточным для сложного вокала
- Не учитывает мелизмы (несколько нот на один слог)
